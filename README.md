## Analisis Performa Algoritma K-Nearest Neighbors (KNN), Support Vector Machine (SVM), dan Random Forest dalam Mengklasifikasikan Spesies Larva Nyamuk 

Proyek ini bertujuan untuk menganalisis dan membandingkan performa algoritma K-Nearest Neighbors (KNN), Support Vector Machine (SVM), dan Random Forest dalam mengklasifikasikan spesies larva nyamuk berdasarkan citra mikroskopik. Penelitian memanfaatkan metode Gray Level Co-occurrence Matrix (GLCM) untuk mengekstraksi fitur tekstur dari citra larva Aedes aegypti dan Culex quinquefasciatus.

Identifikasi spesies larva nyamuk sangat penting dalam mendukung pengendalian penyakit yang ditularkan oleh nyamuk, seperti Demam Berdarah Dengue (DBD) dan filariasis. Melalui pendekatan machine learning, proses identifikasi diharapkan dapat dilakukan secara lebih cepat, konsisten, dan otomatis.

## Dataset
Dataset yang digunakan adalah MLMI-2024 yang diperoleh dari Mendeley Data: https://data.mendeley.com/datasets/pgby6jmtp4/1
